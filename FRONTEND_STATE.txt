=============================================================
TACTICAL PUZZLE — /puzzle
=============================================================
State managed in Puzzle.tsx:
  userSequence     string[]    — player IDs clicked so far (starts with ballCarrier)
  ballCarrier      string      — random node from PRESSABLE_POSITIONS at load
  escapeGraph      NetworkGraph — filtered by formation; injected synthetic CB2
  pressGraph       NetworkGraph — same
  submitted        boolean     — locks the pitch, shows result
  optimalPath      string[]    — computed on submit via computeOptimalPath()
  hoveredEdge      {from,to}   — lifted from PitchGraph → drives PressureMap highlight
  clickFeedback    'safe'|'risky'|'avoid'|null — flash feedback on each click

Derived values:
  optimalNodeId    — highest escape_prob edge from currentCarrier (→ gold ring)
  vacatedZones     — pressing base positions laterally far from ball (→ green wakes)
  blockerMap       — pressing node → nearest escape node (cross-panel highlight)
  progressionValue — fraction of user passes gaining forward ground
  userScore        — average escape_prob along user sequence
  optimalScore     — average escape_prob along computed optimal path

Pass rules:
  - All nodes are clickable (no blocking on avoid-rated passes)
  - Passes with no edge in graph default to escape_prob = 0.25
  - Max 5 nodes in sequence (4 passes)
  - Cannot revisit a node in the same sequence

COMPONENT: PressureMap
=============================================================
File: frontend/src/components/PressureMap.tsx
SVG: W=500, H=320, inner field SVG_W=452, SVG_H=280

Props:
  pressingGraph, escapeGraph, ballCarrierId
  escapeFormation, pressingFormation
  highlightedPresserId?   — from hoveredEdge in Puzzle (cross-panel link)
  threatLayerVisible?     — true after user makes first pass
  pressingTeamLabel?

Visual layers (bottom to top):
  1. Mow-stripe grass pattern + pitch lines
  2. High-line shadow zone (dark rect behind back line) + dashed line + label
  3. Kill zone hatch (diagonal stripes toward touchline behind isolated escape node)
  4. High pressure zone (radial red gradient at ball position)
  5. Trap glow (gold gradient at most-isolated escape node)
  6. Ghost circles (dashed, at base positions of shifted pressers)
  7. Pressing cage web (dashed lines connecting harasser + 2 nearest shadowers)
  8. Cover shadows (blurred red wedge from presser through ball, extending past)
  9. Escape team ghost nodes (blue circles, dimmed when covered, marked when targeted)
  10. Lure run arrow (teal dashed arrow on freest escape player → into space)
  11. Presser reaction arrow (faint red dashed arrow on nearest presser → follows runner)
  12. Harasser charge arrow (pulsing red arrow toward ball carrier, animated opacity+width)
  13. Ball icon (yellow circle)
  14. Pressing nodes (red circles, animated via CSS transform transition)
      - Harasser: large, bright, pulsing halo ring, charge arrow
      - Shadower: medium, patrol zone dashed ring, body-pointer toward nearest escape
      - Anchor: dim, lock icon if close enough to ball
      - All: 0.48s cubic-bezier spring transition on position changes
  15. Intel bar (bottom strip: context-sensitive tactical text)

Dynamic press shift (computeShift):
  - Ball wide (y < 0.28 or y > 0.72): whole block slides 32% laterally toward ball
  - Far-side winger tucks 42% toward center when wide ball
  - CDM steps 34% toward ball side + 16% forward to cut back-pass lane
  - Harasser: 36% toward ball (x) and 36% laterally
  - Backline: gate closes when central, near-side steps out when wide
  - Ghost circles appear at base positions when shift magnitude > 0.045

Lure mechanic (visible when threatLayerVisible):
  - lureRunnerId: escape player with most space (minDist to nearest presser > 0.22)
  - Run arrow: dashed teal, from lure runner toward open space (away from press cluster)
  - Reaction arrow: faint red dashed, nearest presser tracks runner's destination
  - Run destination glow: small teal circle at end of run arrow

COMPONENT: PitchGraph
=============================================================
File: frontend/src/components/PitchGraph.tsx
SVG: W=500, H=320, PX=24, PY=20

Props:
  graph, formation, interactive, highlightSequence
  onNodeClick, ballNodeId, onEdgeHover
  optimalNodeId?   — pulsing gold ring on best available target
  vacatedZones?    — green wake glows at positions pressers left

Edge visual:
  - Active (from current carrier): colored by escape_prob
    Safe (≥0.65): rgba(88,166,255) solid
    Risky (0.35–0.65): rgba(227,179,65) solid
    Avoid (<0.35): rgba(248,81,73) dashed
  - Sequence edges: teal solid, numbered badge at midpoint
  - Ghosted edges: rgba(255,255,255,0.08), opacity 0.30
  - Nodes with no edge to carrier: faint dashed attempt line
  - Wide transparent hit area (strokeWidth 16) on active edges for hover

On-hover overlays (hoveredEdgeFull):
  - Exposed zone: green ellipse behind target in direction of travel (prob ≥ 0.35)
  - Lead pass: dashed teal extension + dot 22px past target (safe forward passes)
  - Passing window: perpendicular brackets at midpoint; gap = 6 + p*18px
  - Floating tooltip: "Risk X% | Gain +Ym | Lane open/narrowing/closed"

Predictive arc (optimalNodeId, always visible when interactive):
  - Marching-dashes teal arc curving to lead point 28px ahead of target
  - Pulsing crosshair at lead point (r animates 7→14, opacity 0.9→0.4)

Vacated zones (vacatedZones, always visible when interactive):
  - Green radial gradient circles pulsing at staggered intervals
  - Small dashed ring inside, both pulse independently

Node visual:
  - Ball carrier: gold dashed ring, ball icon offset top-left, pulse ring animation
  - Sequence nodes: teal (last) or blue (intermediate), numbered badge on edges
  - Optimal node: pulsing gold outer ring (r 7→14px, 1.4s loop)
  - Covered node (escape_prob < 0.28, not in sequence): opacity 0.45
  - Key outlet (inf ≥ 0.65, not carrier, not in sequence): blue outer ring
  - Size: 11 + nodeInfluence*5 base, min 15 when in sequence

Click feedback (Puzzle.tsx → via CSS class):
  safe → blue flash, risky → yellow flash, avoid → red flash

=============================================================
SCORING + RESULT
=============================================================
sequenceScore:   avg escape_prob across all edges in sequence
optimalScore:    avg escape_prob of computeOptimalPath (greedy best-first, 4 hops)
progressionValue: fraction of passes gaining forward x (0–1)
medal:  GOLD (ratio ≥ 0.9) | SILVER (≥ 0.7) | BRONZE (≥ 0.5) | MISS (<0.5)
verdict: plain English sentence based on ratio band
